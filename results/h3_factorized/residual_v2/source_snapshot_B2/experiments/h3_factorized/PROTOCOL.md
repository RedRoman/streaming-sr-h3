# Candidate B: reversible appearance chart around persistent H3 content

This is a frozen-H3-representation pilot, not an end-to-end H3 DiT result and not a real-motion benchmark. Native MiniMax-H3 VAE weights and official latent normalization stay frozen. Native 256×22 context uses22 copies of each already observed anchor, never future frames or22 measurements. The eight physical stages are: far neutral A, far relit A, near relit A, no-visible query, neutral return A, near changed content B, far second relighting B, exact duplicate of the last packet. Near sensing uses a128-pixel central footprint at2× degradation versus4× at far range. Visibility/reveal masks describe this sensor footprint and do not use change/HR labels.

The proposed trainable core is a24-channel content memory plus12-dimensional appearance read query. Four alternating conditional affine couplings define F(c,a), exact inverse F^-1, with F(c,0)=c. A learned LR-pair appearance encoder and shared gated LR-only evidence update operate in canonical content coordinates. Only a new visible packet can update memory; query is read-only and duplicate packet IDs are idempotent. Appearance is a reversible read chart rather than an irreversible overwrite of content. Conditional flows and content/appearance disentanglement themselves are standard ideas; novelty is a candidate claim about learnable canonical evidence transport and counterfactual identity-preserving writes, which requires comparison and real streaming integration.

Four matched models: factorized+swap144748 parameters, identical factorized without swap144748, noninvertible separate chart/inverse144614, mixed memory143748. State tensors have the same24 channels; appearance/update heads are identical. Model initialization keeps AppearanceEncoder.head zero and chart last weights small random (.005). Zeroing both would kill the conditional gradient. Synthetic protocol audit and actual train batch gradients are saved. The update residual bound is shared2.0, explicitly revised from draft.2 after actual train H3 SR residual RMS≈.984 showed that.2 would prevent useful correction.

Sources use official BSDS500 source-level train/val/test, selecting32/8/16 sorted source IDs. Local content B replaces the central patch using the next source from the same split; all donor IDs/hashes are recorded. Physical relighting consists of RGB gain/bias and six smooth shading basis coefficients. HR image/latent/appearance parameters only enter training and evaluation supervision; observe/query signatures consume actual degraded LR tensors, footprint and packet IDs. Cache stores inputs and supervision separately. No generated image becomes an evidence packet. Test tensors are not loaded by training scripts.

Fixed stage1:600 Adam steps, batch4, lr.002; each kind receives the exact same seeded source-batch schedule; loss = rollout latent L1 +10×appearance parameter MSE +.5×counterfactual swap/canonical invariance L1. No-swap omits only counterfactual loss. Query and duplicate receive no extra training weight. Validation every100 steps selects the shared recurrence+appearance score, avoiding auxiliary-loss differences in selection.

Fixed stage2:200 Adam steps, batch4, lr.0005; warm start stage1 selected checkpoint; same stage2 source schedule. Every4th step one sample/stage also incurs5×actual native frozen-H3 decoded RGB L1, cycling the five unique new-evidence stages. Frozen D differentiation temporarily uses upstream eager RoPE because the inference fused kernel lacks autograd; context restores native path immediately. This exact wrapper gets a true native-vs-eager RGB parity and input-gradient audit before fine tuning. Validation every50 steps selects actual native D mean RGB L1 on8 val sources×5 stages. All four controls get identical decoder/update budgets. Final seeds17/29/43 use the same fixed protocol, and16 test sources are evaluated only after protocol fixation.

Report actual native FP16 decoder RGB PSNR whole image, near ROI and unchanged outside ROI at five stages; current bicubic LR, native H3 D(E(current LR)), and H3 HR roundtrip are explicit reference rows. Record appearance leakage, approximation-free inverse error, state bytes, read-only and duplicate invariants. Bootstrap source episodes and report per-seed means; donor sharing makes adjacent episodes dependent and limits generalization. Do not equate latent L1 reduction, short controlled return, or exact invertibility with real video SR quality.

Precision audit: initial seed17 validation used default CUDA TF32 for float32 chart convolutions. Trained algebraic inverse errors reached.0056 max under TF32. The same checkpoints audited on CPU strict FP32 give max1.62e-5/RMS≈1e-6, identifying arithmetic roundoff rather than a wrong inverse formula. Final heldout chart evaluation disables TF32 explicitly; native VAE D stays FP16. Initial val metrics remain retained with their original precision behavior. This is a precision correction, not a metric-driven architecture/hyperparameter change.

Shared classical DC control: after fixed three-seed training, data construction re-executes the original simulator's physical noisy LR measurements and requires bitwise equality of every cached upsampled-LR RGB tensor, all56 sources. Stored runtime observation files contain no HR. The affine operator is measured from1D basis through the same Gaussianσ.6/5-tap reflection blur and Torch bicubic antialias. A separable pseudoinverse and64-step affine/box Dykstra project every compared output with the same current measurement; an explicit operator test compares it to the simulator. Far/return stages constrain the full4× observation. Near stages constrain only the actual central128 footprint at2×; outside pixels are untouched. No-visible queries, neutral counterfactual queries and oracle-chart swaps are never given invented measurements. This is a standard consistency control and carries no novelty claim.

Predeclared error-source oracles are reported separately, never as valid LR-only methods: (i) full model receives the true physical appearance parameters at each step to isolate LR appearance estimation error; (ii) full model starts from the HR initial identity latent, then uses only the normal LR updates, to isolate whether a correct initial detail identity would survive. These are diagnostics, not training or test-driven model selection, and receive no invented LR projection for counterfactual queries. The actual proposed/competing methods remain strictly LR-only.
