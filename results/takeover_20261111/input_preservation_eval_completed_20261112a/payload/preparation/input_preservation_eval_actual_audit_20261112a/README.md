# Saved-array evaluation audit (prepared only)

`audit_actual.py --execution-contract FILE --out NEW_DIR [--execute]` uses only NumPy and the Python standard library. Default inspection reads metadata, never NPZ arrays. Root fills the two terminal path/SHA bindings and supplies a separately authorized 900-second / 2-CPU / 4-GiB bounded launcher. This entry does not implement its own wall-clock/RSS supervisor. Set BLAS/OMP thread limits to 2 and TORCH_DEVICE_BACKEND_AUTOLOAD=0 before starting. No SSH or actual cache audit was performed during preparation.

Execution streams 180 original six-array RGB NPZs and 180 saved five-array evaluation NPZs. It verifies all file and array hashes, 2,880 record identities, threshold-zero masks, 23,040 reconstructed raw/clipped RGB hashes, row metrics, source/profile/phase and control aggregation, and 2,850 adjacent pairs. MAE/MSE/seam/coverage/LPIPS reaggregation tolerance is 1e-12; PSNR tolerance is 1e-10; bytes, shape/dtype, null/boolean and identity checks are exact. Signed-zero ties keep raw; clipping preserves signed zero. LPIPS distances are authenticated and reaggregated, not recomputed by a model. Scores are authenticated but the learned head is not rerun. The accepted prior cache audit supplies the raw-feature/teacher provenance; this audit does not repeat those model/feature operations.

The source screen outcome is retained verbatim after its underlying reported statistics are verified. This tool does not reimplement the screen, change its criteria, select a threshold, authorize training, or declare quality. Producer frozen-model/runtime assertions are checked as attestations, not newly demonstrated by this NumPy process. A scientific failed screen may have a successful artifact audit.

Outputs are a small atomic progress.json and audit.json in a new directory outside all producer artifacts. Any execution exception writes complete=false/status=failed with the existing progress. No original evaluation file is modified; no arrays or checkpoints are copied. Root can archive these small files with the original evaluation JSONL and source/contract evidence after completion.
