# Stage 4 协议：因果化的代价，以及观测锚定在因果设定下的作用

日期：2026-10-17。本文件在任何 Stage 4 输出产生之前写定；之后只追加。

## 为什么做这个

H3 的 DiT 是双向的（`comfy/ldm/minimax/model.py` 的 Attention 以 `mask=None` 调用），块内每一帧都能看到块内的未来帧。因此当前的"流式"只是按块因果，**块长就是等待时间的下界**（22 帧 = 0.9 秒），而且块内计算无法增量复用。真正的流式要求 DiT 本身因果。

把双向模型改成因果通常要掉质量。本阶段先在**不训练**的前提下测出这个代价，为后续训练定基线；同时检验观测锚定的思想在因果设定下是否比在块间接续里更有用——因果注意力的 KV 缓存同样携带自生成历史，累积问题在那里更本质。

## 实现

在 `Attention.forward` 外加一层掩码，只影响目标视频段的行之间的可见性，文本、条件关键帧、音频段一律保持全可见（它们本就是给定条件，不涉及因果）。

视频段共 `latent_t` 个 latent 帧、每帧 `frame_rows` 行。记行 i 的 latent 帧序号为 `t_i`。掩码规则：
- `bidir`：无掩码（现状，用作参照，必须与 mask=None 的输出逐位相同）；
- `causal`：允许 `t_j <= t_i`，即严格因果到 latent 帧粒度；
- `causal_cw{C}`：块因果，允许 `floor(t_j/C) <= floor(t_i/C)`，同一 chunk 内双向。取 C=2（latent 帧，约对应 5–6 个像素帧）。

掩码按 (text_len, latent_t, h, w, audio_t, keyframes) 签名缓存一次，不每步重建。

## 实验

数据与 Stage 2/3 完全相同：12 条片段、124 帧、7 块、重叠 5 帧，Stage 1 的 LoRA + innerDC、seed 101。块间一律用 `indep`（Stage 3 已证明接续不划算）。

变体：
- `bidir`（= Stage 2 的 indep，复用已有结果，不重跑）
- `causal`
- `causal_cw2`
- `causal_anchor`：在 `causal` 基础上，把 Stage 3 的高频能量配额用于约束**块内**的生成——以同块 `bidir` 的输出为能量参照，对因果输出做同样的配额。用于检验观测锚定在因果设定下的作用。

指标与 Stage 2/3 同口径。先片段内平均再片段等权，配对差给 bootstrap 95% 区间（10000 次，种子 0）。

## 判读（预先写定）

1. **因果化代价**：报告 `causal − bidir` 与 `causal_cw2 − bidir` 的 PSNR / LPIPS / 能量 / 余弦。这是后续训练必须弥补的量，没有通过与否之分。
2. **chunk 宽度**：若 `causal_cw2` 的画质损失显著小于 `causal`（LPIPS 差值区间不跨 0），则块因果是更划算的折中，后续训练以它为目标。
3. **观测锚定在因果下的价值**：若 `causal_anchor − causal` 的 LPIPS 改善 ≤ −0.01 且区间不跨 0，则观测锚定在因果设定下有效，应纳入 Stage 5 的训练设计；否则记录为无效，不再在推理期使用锚定。

## 已知局限

- 掩码只改变注意力可见性，RoPE 位置编码不变；真正的流式推理还需要 KV 缓存与位置重对齐（SolarWM 的做法），本阶段不实现，因此不报吞吐改善。
- 不训练，所以测到的是"直接施加因果掩码"的代价上界；训练可以显著弥补。
- 12 条片段，评测素材为生成视频。
