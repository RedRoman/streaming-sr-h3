# 第 3 步（Stage 1 试训）协议：H3 复原适配 LoRA

日期：2026-10-16。本文件在任何训练输出产生之前写定；之后只追加。

## 目的

前三步证明：冻结 H3 的复原能力不足（生成细节只有 GT 的 36%），给它记忆或参考都救不回来，而且同条件下不如经典投影。本步检验：在 H3 上训练一个复原 LoRA，能否在相同的流式分块协议下胜过冻结基线。这是后续因果化、流式、音视频联合的前置条件；若不通过，整条"H3 为底座"的路线需要重新评估。

## 训练设定

- 底座：冻结 MiniMax-H3 FL2VA pruned BF16（SHA a32572fb…），ComfyUI 实现，commit 5a66589。
- LoRA：rank 32，alpha=rank，挂在全部 50 个 block 的 `attn.qkv_proj`、`attn.out_proj`、`mlp.fc1`、`mlp.fc2`；B 零初始化（零适配器与底座逐位相同）。约 1.72 亿可训练参数。
- 条件：官方关键帧 guide 通道，与冻结基线完全相同的接口（低清经官方预处理后 VAE 编码）。通道拼接留作后续变体，不在本步。
- 目标：视频流 flow-matching 速度场 MSE 到 `eps − z_HR`；音频流输入噪声、不计损失。
- sigma 采样：均匀 u，`sigma = 12u/(1+11u)`（与官方 shift 12 的网格一致），裁剪到 [0.02, 0.995]。
- 优化器：AdamW，lr 1e-4，warmup 100 步，betas (0.9,0.999)，weight_decay 0，梯度裁剪 1.0。
- 规模：8 卡数据并行，每卡 batch 1，等效 batch 8；2000 步（约 1.6 万样本，4364 个训练样本约 3.7 个 epoch）。
- 梯度检查点开启；底座参数全程冻结（每次保存时审计版本号与梯度）。

## 数据

- 来源：`/temp/h3_unified_dataset_20260918`（只读），2182 train / 114 val clip，按同事已有的 source-group 划分，训练与验证不共享来源。
- 每个 clip 取 2 个窗口，22 帧、24 fps、832×480（Lanczos 缩到 480 高后随机水平裁剪，不放大）。
- 退化（片段内参数一致）：25% 概率用评测同款 Pillow BICUBIC ×4；其余为 Real-ESRGAN 式链：模糊 → ×4 缩放 → 噪声 → H.264(crf 18–37) 或 JPEG(q 35–95)，30% 概率叠加二阶。
- 重要局限：训练数据全部是生成视频（H3 自生成、Seedance、Ostris），评测用的是真实视频（LaSOT/DAVIS），存在域差异。这是本步的已知弱点，结果中必须说明。

## 验收（预先写定，以像素指标为准）

训练中的 velocity MSE 只作监控，**不作为判据**（同事此前的失败正是 velocity 降了 10% 但画质没提升）。

最终以固定权重（最后一步，不按验证集挑 checkpoint）在**从未进入训练的真实视频**上读出：第 0 步的 32 个 kpost 块，49 步 Euler、CFG 1、seed 101，分两种读出：
- `lora_base`：不加采样内投影；
- `lora_innerdc`：加与冻结基线相同的采样内投影（修正点 28/45/48）。

对照为第 0 步已有的 `fl2va`（冻结 + innerDC）与 `none_rerun`（逐事件完全相同）。指标为目标框内 PSNR / LPIPS、生成频带能量比与余弦、整帧 PSNR、LR 一致性，事件内平均后事件等权，配对差给 bootstrap 95% CI。

判据：
1. **通过**：`lora_innerdc − fl2va` 的目标框 LPIPS ≤ −0.02 且区间不跨 0，同时 PSNR 不低于 −0.2 dB；或 PSNR ≥ +0.3 dB 且 LPIPS 不升。
2. **部分通过**：生成频带能量比显著上升（≥ +0.1）且与 GT 的余弦上升（区间不跨 0），但 PSNR/LPIPS 未达阈值。此时判为"训练确实提升了细节生成，但规模不足"，可据此申请更大规模训练。
3. **不通过**：以上都不满足。此时需要重新评估"H3 作为复原底座"，考虑换底座或换方向。

另报：相对经典投影基线 `classic_none`（32.92 dB / 0.219）的差距，用于回答第 2 步暴露的"H3 是否值得"。

## 已知局限

- 训练数据是生成视频，评测是真实视频，存在域差异；若不通过，需要先排除这一项再下结论。
- 只训视频流，音频固定噪声且不计损失。
- 22 帧块低于 H3 的训练长度（124–362 帧），这一偏差在冻结基线和训练模型上同时存在，不影响配对比较。
- 等效 batch 8、2000 步属于小规模试训，不足以代表充分训练的上限。
