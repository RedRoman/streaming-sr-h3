# Stage 3 协议：用低清观测锚定的块间接续（观测锚定接续）

日期：2026-10-17。本文件在任何 Stage 3 输出产生之前写定；之后只追加。

## 问题

Stage 2 给出两个基线，各有一半缺陷：
- `indep`：块独立，画质好（PSNR 27.06 / LPIPS 0.205 / 能量 1.01），但块之间不传任何信息；
- `carry`：把上一块输出接给下一块，边界一致性变好（−0.118），但误差累积——能量 1.01→1.83 远超真值，PSNR −0.87、LPIPS +0.034、余弦 −0.049，块内闪烁 1.00→1.65。

本阶段检验：**在接续的同时，用每块都能获得的真实低清观测把累积压住**，能否同时胜过两个基线。

## 方法：观测锚定接续

接续的内容仍是上一块输出的重叠 5 帧，但写进 guide 之前先做两步约束，二者都只用当前块的低清观测（部署时可得）：

1. **低频替换**：接续内容 P 的低频一律来自当前观测。
   `P' = U(LR_t) + N(P)`，其中 `N(x) = x − U(D(x))`，D 为抗混叠 bicubic ×4，U 为 bicubic 上采样。
   这保证接续只携带高频，低频永远被当前观测重置，杜绝低频漂移。

2. **高频能量配额**：限制接续携带的高频能量不超过当前观测所能支持的水平。
   以本块 `indep` 方式的输出 Y0 为参照（同一块、同一 seed、不接续），令
   `r = ‖N(P')‖ / ‖N(Y0)‖`（整帧上计算），若 `r > τ` 则按 `N(P') ← N(P') · τ / r` 缩放。
   τ = 1.0 预先固定，不调参。理由：接续不应比不接续生成更多高频；Stage 2 中 carry 的能量涨到 1.83 正是越过了这条线。

两步都只作用在重叠的 5 帧上，其余 17 帧的 guide 与 `indep` 完全相同。采样设定（49 步 Euler、CFG 1、seed 101、innerDC 修正点 28/45/48）与两个基线完全一致。

变体（每条片段都跑）：
- `anchor`：上述完整方法（低频替换 + 能量配额）；
- `anchor_lowfreq_only`：只做第 1 步，不做能量配额——用于分离两步各自的贡献；
- 基线 `indep`、`carry` 复用 Stage 2 已有结果，不重跑。

## 数据与评测

与 Stage 2 完全相同：同样 12 条片段、124 帧、7 块、重叠 5 帧，同样的退化与 seed。指标与 Stage 2 同口径：块边界不一致、边界/块内比值、边界与块内闪烁、整段 PSNR / LPIPS / 能量比 / 余弦、每块耗时。先片段内平均再片段等权，配对差给 bootstrap 95% 区间（10000 次，种子 0）。

## 判读（预先写定）

**主判据（必须同时满足）：**
1. 相对 `carry`：PSNR、LPIPS、余弦三项都不差于 carry，且其中至少两项的改善区间不跨 0；能量比落回 [0.8, 1.3]（即不再超发）。
2. 相对 `indep`：块边界不一致降低且区间不跨 0；同时 PSNR 不低于 −0.2 dB、LPIPS 不升（区间不跨 0 的变差即判失败）。

同时满足 → **观测锚定接续成立**，可作为 Stage 4 因果化与少步数蒸馏的条件设计。

**部分成立**：只满足第 1 条（修好了 carry 的累积）但未满足第 2 条（相对 indep 没有净收益）。此时结论是"锚定能让接续可用，但接续本身在当前设定下没有带来增益"，需要重新评估块间传递的价值——因为 Stage 2 已表明块边界问题本就不大。

**不成立**：第 1 条都不满足。则低清锚定无法抑制累积，需换方法（例如在训练中展开多块、或改为latent 域锚定）。

**消融**：`anchor` 与 `anchor_lowfreq_only` 的差给出能量配额的单独贡献；若两者无显著差异，报告中必须写明配额未起作用。

- τ = 1.0 为预先固定值，不做扫描；若结果显示它是瓶颈，只能作为后续工作记录，不在本阶段调整。
