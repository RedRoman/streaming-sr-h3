# Stage 2 结果：块边界问题不大，但简单接续会累积误差

2026-10-17。协议 `PROTOCOL_stage2.md`（判读规则在出数前写定）。12 条 VIDGEN 片段（与 Stage 1 的 16 条不重叠），每条 124 帧、7 个块、块间重叠 5 帧，Stage 1 的 LoRA + innerDC，seed 101。两种方式各 84 个块，0 失败。本阶段不训练。

## 主要结果

| 指标 | indep（块独立） | carry（接续上一块） |
|---|---:|---:|
| 块边界不一致 | 0.7587 | 0.6409 |
| 块内相邻帧变化 | 0.9822 | 0.9710 |
| **边界 / 块内** | **1.2685** | 1.1761 |
| 边界处闪烁（相对 GT） | 2.5459 | 3.8208 |
| 块内闪烁（相对 GT） | 0.9972 | 1.6506 |
| PSNR | 27.0592 | 26.1893 |
| LPIPS | 0.2050 | 0.2389 |
| 生成频带能量 / GT | 1.0148 | 1.8312 |
| 与 GT 余弦 | 0.4513 | 0.4028 |
| 每块耗时（秒） | 129.55 | 129.17 |

边界/块内比值的 95% 区间：indep [0.74, 1.85]，carry [0.67, 1.70]。

carry − indep 的配对差：边界不一致 −0.1178 [−0.1836, −0.0544]；PSNR −0.8699 [−1.3270, −0.4118]；LPIPS +0.0339 [+0.0131, +0.0595]；能量 +0.8164 [+0.3894, +1.3016]；余弦 −0.0485 [−0.0758, −0.0223]；闪烁比 −0.2074 [−0.5784, +0.0648]。

## 判读（按预注册规则）

**第一条：不成立。** 判据要求边界/块内比值 ≥ 2 且区间不跨 1，实测 1.27 且区间跨 1。结论：在训练后的模型上，同一帧被相邻两块各生成一次的差异，与块内相邻帧之间的差异处于同一量级，**块边界不是一个独立的严重问题**。

这修正了第 0 步的印象。第 0 步在冻结模型上测到 35% 的相对差异，但那是冻结模型、且未用完整流式协议。块内闪烁比值 0.9972 恰好等于真实场景的帧间变化，说明流内部的时序行为是健康的；边界处 2.55 偏高，但基数小。

**第三条：成立，且是本阶段最重要的结果。** carry 降低了边界不一致（区间不跨 0），但画质三项指标全面变差（PSNR、LPIPS、余弦，区间均不跨 0），生成频带能量从 1.01 升到 1.83（远超 GT 水平），块内闪烁从 1.00 升到 1.65。

这是误差累积的直接证据：把上一块的输出当作下一块的条件，模型将自身生成的细节当作真实观测，逐块放大，最终超出真实水平近一倍，并且时序更不稳。**OmniVR（2608.04224）在论文中承认 anchor 误差会跨窗口累积并将其列为未来工作，本结果在 H3 上独立复现并给出量化。**

## 对后续的影响

1. 原计划的"块间传递高清信息"不能直接使用，它会累积误差。
2. Stage 3 的问题因此明确为：**在接续的同时，用每块都能获得的真实低清观测抑制累积。** 这使低清观测锚定从可选优化变为必要条件。
3. 已有两个基线：indep（画质好但不传信息）与 carry（传信息但累积误差）。Stage 3 必须同时胜过两者才算有贡献。

## 时延

每块 129.55 秒，其中采样 120.0、VAE 解码 1.06、guide 编码 2.72。块长 22 帧、重叠 5 帧，故每块等待 17 帧（24fps 下 0.708 秒）。当前为 49 步采样；4 步 Turbo LoRA 已就绪（`assets/turbo/`），Stage 3 将使用。

## 局限

- H3 的 DiT 仍为双向，本阶段"流式"仅指按块因果处理，块内仍双向。真正的因果化在 Stage 3。
- 12 条片段规模小，仅用于建立基线量级。
- 评测素材为生成视频，真实视频的块间行为需另测。
