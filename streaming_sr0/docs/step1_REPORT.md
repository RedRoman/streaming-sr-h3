# 第 1 步结果：冻结 H3 不能从高清参考图搬运细节

2026-10-16 19:35。协议见 `PROTOCOL_step1.md`（判读规则在出数前写定）。32 个 LaSOT 回访事件的 kpost 块，每块 4 种参考条件，共 128 个块，0 失败。Ref2VA pruned BF16 + LR 关键帧 + innerDC，seed 101，其余与第 0 步相同。

## 主要结果（目标框内，32 个事件等权）

| 条件 | PSNR | LPIPS | 生成频带能量/GT | 与 GT 余弦 |
|---|---:|---:|---:|---:|
| FL2VA 无参考（第 0 步） | 30.46 | 0.191 | 0.34 | 0.384 |
| Ref2VA 无参考 | 29.46 | 0.202 | 0.36 | 0.349 |
| Ref2VA + GT 参考 | 29.04 | 0.208 | 0.38 | 0.337 |
| Ref2VA + 自身输出参考 | 28.96 | 0.209 | 0.38 | 0.334 |
| Ref2VA + 无关参考 | 28.98 | 0.209 | 0.38 | 0.334 |

相对 Ref2VA 无参考的事件配对差（bootstrap 95% CI）：
- GT 参考：PSNR −0.42 dB [−0.64, −0.24]，3/32 个事件改善；LPIPS +0.006 [+0.003, +0.009]。
- 自身输出参考：PSNR −0.50 dB [−0.76, −0.29]。
- 无关参考：PSNR −0.48 dB [−0.75, −0.26]。
- GT 参考减无关参考：PSNR +0.06 dB [−0.04, +0.16]，16/32 个事件更好；LPIPS 与余弦的区间同样跨 0。

## 判读（按预注册规则）

主比较 GT − 无参考没有达到 +0.3 dB / −0.02 LPIPS，而且方向相反，区间不跨 0。结论：**冻结 H3 的参考通路在这个设定下不能搬运细节**。加任何参考图都会让结果变差约 0.45 dB，并且变差的幅度与参考内容无关（GT 和无关图像无法区分）。参考图让生成能量略增（+0.02），但与 GT 的一致性下降，属于多生成了一点不对的纹理。

另外，即使不给参考，Ref2VA 权重也比 FL2VA 差 1.0 dB [+0.67, +1.37]（28/32 个事件），说明 Ref2VA 本身就不适合做"低清关键帧引导的复原"。

## 排除实现错误（事后诊断）

在 3 个事件上截取 DiT 第一次前向：
- 有参考时打包序列包含 `ref_img` 段，`cond_video_latents` 为 2 个，序列长度从 5987 增加到 6377，说明参考图确实进入了 DiT；
- 换参考内容（GT 与无关图）会使预测速度场相对变化 2–5%，只去掉参考行变化 2–9%，说明模型读了参考图，但这一影响没有转化为对 GT 的贴近。
- 目视（monkey-11 等）：4 种 Ref2VA 输出几乎相同，都没有恢复 GT 的毛发纹理，脸部出现了参考图里没有的花纹。

## 局限

- 只测了官方的条件方式：整帧参考、`match` 缩放、单张参考、49 步、CFG 1。没有测参考裁剪到目标、CFG 大于 1、多张参考。
- LR 关键帧覆盖整个视频，可能压过参考；Ref2VA 训练时大概率没见过这种组合。
- 面板脚本对很宽的目标框排版有问题（如 tiger-7），不影响指标。
