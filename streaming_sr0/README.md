# streaming_sr0 — 以 MiniMax-H3 为底座的流式全退化视频复原

2026-10-16/17。本目录是 `streaming-sr-h3` 项目的接续工作，与仓库根目录下 2026-10-15 的归档相互独立：那一轮验证的是"冻结 H3 + 记忆状态"，本轮在其结论基础上转向训练与流式。

所有阶段的判读规则都在各自的 `PROTOCOL_step*.md` / `PROTOCOL_stage*.md` 中，**于出数之前写定**；报告中保留了全部负面结果。

## 一、结论链

| 阶段 | 问题 | 结论 |
|---|---|---|
| Step 0 | 冻结 H3 流式复原在回访时会丢失细节身份吗 | **测不出**。瓶颈是生成细节太少（GT 的 36%），方向也不准（余弦 0.37） |
| Step 1 | 给它高清参考图能搬运细节吗 | **不能**。PSNR −0.42，且给真实参考与给无关图像无差别 |
| Step 2 | 把记忆写进它会跟随的 guide 通道呢 | **收益不足**。上界仅 +0.088 dB；内容检查通过（真实记忆优于无关内容 +0.27 dB），但同 guide 下 H3 比经典投影低 2.55 dB |
| **Stage 1** | 训练能把复原能力提上来吗 | **能**。LPIPS −0.087（16/16），细节能量 0.30→0.83，余弦 0.297→0.434，PSNR 不降 |
| Stage 2 | 流式分块的真问题是什么 | 块边界问题**不大**（边界/块内 1.27，区间跨 1）；**简单接续会累积误差**（能量 1.01→1.83） |
| Stage 3 | 用低清观测锚定能修好接续吗 | **部分**。相对 carry 六项全改善，但相对块独立仍差 → 复原任务里**块间接续本身不划算** |
| Stage 4 | 因果化要付多少代价 | **很小**。PSNR −0.155、LPIPS +0.0146，仅为 Stage 1 训练收益的六分之一 → 可行 |

前三步的负面结果构成训练的动机：**问题不在"记忆怎么存"，而在复原能力本身未适配。**

## 二、与现有工作的关系

- [OmniVR](https://arxiv.org/abs/2608.04224)（LTX-2，音视频复原）：离线窗口串联，论文承认 anchor 误差跨窗口累积并列为未来工作。本工作在 H3 上独立复现该现象并给出量化（能量 1.01→1.83）。
- [FreqForcing](https://arxiv.org/abs/2607.27110)：同样把累积诊断为频域能量漂移并用锚定抑制，训练无关。**区别**：其锚为冻结的自生成帧（因此付出多样性下降代价），本工作的锚为每块新到的真实观测；其约束为低通软混合，本工作为硬能量配额；其任务为生成。必须引用并做直接对照。
- [SwiftVR](https://arxiv.org/abs/2606.09516) / [FastVR](https://arxiv.org/abs/2609.36757) / [ReCaVSR](https://arxiv.org/abs/2609.37831)：流式复原，但只做视频，底座为 Wan。
- [SolarWM](https://arxiv.org/pdf/2609.02886)：把 H3 改为因果的完整三阶段流程，但做世界模型生成，音频填静音。

**"H3 + 流式 + 音视频 + 全退化"的组合目前为空。**

## 三、方法与设定

- 底座：冻结 MiniMax-H3 FL2VA pruned BF16（Comfy-Org@e5eb578，SHA 校验），ComfyUI 实现 commit `5a66589`。
- Stage 1 训练：LoRA rank 32 挂在 50 个 block 的 qkv/out/fc1/fc2（1.72 亿参数），2000 步，8×910B，等效 batch 8。
- 退化：片段级参数一致。25% 用评测同款 Pillow BICUBIC ×4，其余为模糊 → ×4 缩放 → 噪声 → H.264(crf 18–37) 或 JPEG(q 35–95)，30% 叠加二阶。
- 流式分块：块长 22 帧、重叠 5 帧、新输出 17 帧；块 k 覆盖 [17k, 17k+22)。
- 评测：两组互补——VIDGEN 原生 1344×768 同域（画质与 demo），LaSOT 压缩真实视频跨域（泛化）。训练集与两组评测集均无交集。

## 四、关键教训

1. **代理指标必须与交付物同域。** latent 距离与像素质量非单调：LBH latent 上采样的 latent 距离更近（0.545 vs 0.731），解码后却差 8.4 dB。训练的 velocity MSE 同理，只作监控不作判据。
2. **评测素材的真值不能糊。** LaSOT 的 GT 是 720p 网络视频缩到 480 高，导致模型生成的正确细节被算作误差（PSNR −0.82）；换成原生 1344×768 后 PSNR 不降而 LPIPS 改善更大。
3. **能量与方向要一起看。** 若生成的是噪声，能量升而余弦降；本工作两者同升，证明细节方向正确。
4. **先验证机制是否真的生效。** 掩码接口先用全可见掩码做逐位一致性检验；锚定先确认配额确实被触发。
