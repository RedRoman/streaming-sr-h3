## Included

## Excluded

Model weights, learned checkpoints, large binary caches, input/output frame collections, downloaded external repositories, virtual environments, terminal logs, live session/PID state and credentials are not included. Paths referenced by reports may therefore point to local-only artifacts. No source dataset or H3 weights are redistributed here.

## Reproducibility

This is a research archive, not a one-command packaged release. Re-running GPU experiments requires separately obtained MiniMax-H3 weights, the matching ComfyUI source, datasets and CUDA dependencies. Paths in experiment scripts may need adjustment. Dataset identities/splits and artifact hashes are retained for verification. Hardware-specific and historical absolute paths in source/provenance describe the original runs.

The captured source and all included JSON were checked for parseability. Experiment training was not rerun while publishing this snapshot. Files were copied only after checking that each file's size and modification time stayed stable during the read; ongoing runs can still make related files reflect slightly different moments.
