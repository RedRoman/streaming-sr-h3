# Independent review after A raw/DC900 and B decoded-v4

This is a design assessment, not a new trained result. No additional DiT or training job is started. It uses the completed A conditional-response pilot and B's fixed32train/8val, seven×672 actualD experiment.

## What must change before a new core claim

B's retained pre-lift actual24-channel observation contains useful detail: the existing single-packet, pixel-photo-bridge control reaches26.7445dB, while the old learned lift/readout reaches23.5511. B decoded-v4 repairs the sparse RGB objective but full24.11443 remains almost equal to current-image anchor24.10618; removing/shuffling measured history changes only0.00112/0.000535dB. This is evidence that the *complete trained system* obtains little usable information from history. It does not identify lift, action or read as the sole cause, or prove4ch is fundamentally insufficient; the single-TRAIN RGB fit is a counterexample to a simple capacity impossibility claim.

There is an architectural shortcut worth isolating. `RevisionMemory.read` computes f(h,z,a,w)−f(0,z,a,w). A nearly constant nonzero h can open a z-conditioned SR function without conveying packet-specific detail. The zero-h property is valid but does not force history dependence. Similarly, a nonzero latent gradient or feature variance does not prove useful evidence transmission. The matched anchor-only model and drop/shuffle interventions correctly expose this ambiguity.

A's new pilot has a different limitation: all3 support guides already contain A+B, and only then are they compressed. Prefix auditing shows q(g|u) already at the center after A in all6sources, with I(u;g)≈0; AB changes carrier weights rather than resolving correlated geometry/content alternatives. Hence the completed raw/DC900 is a conditional-response representation experiment, not a causal association-retention experiment. Final posterior concentration alone would not have implied this; the early probabilities and actual compression timing do.

## Required quality-preserving carrier, which is a baseline

Retain an information-preserving measurement path. Prefer original near LR+packet ID+geometry/appearance estimate if its storage is lower than full24 native codes. A64×64 RGB FP32 packet is49152B; a native24×7×16×16 code is172032B before proxy and masks. An exact pixel-unshuffle of LR changes layout, not information, and can feed a network without paying a random learned compression bottleneck. A decoded/native full24 path can be an independent fidelity control, not assumed superior to keeping LR.

Initialize the final readout to an existing LR-only photo/reliability atlas or full24/pixel-photo bridge, with exactly zero learned correction. Keep the common current-LR DC. The first forward must reproduce that bridge, and a single-packet measured change must affect the output before training. In contrast to a free f(h,z)−f(0,z) decoder, the observed carrier itself reaches RGB without needing the neural head to discover how to transmit it.

This skip, the physical atlas, retained packet archive, photo rebase and replay are established controls. They are not the proposed novelty and must be shared by the learned alternatives. Removing the skip is a diagnostic, not a weak main baseline. Lossless archival also does not provide a state-compression claim; actual total state/controller/model/cost must be counted.

## Candidate learning mechanism: conditional revision of an uncertain carrier action

The remaining research hypothesis is a *causal operator-conditioned generative correction field*, carried beside the retained observation rather than replacing it. At an early prefix, an LR-only correspondence/appearance controller supplies an unresolved set or low-dimensional distribution of plausible interpretations g. Write the lossless datum once. The learned side state stores how that datum's contribution to the frozen H3-native readout changes with g, including content/operator interaction; it must not store only a single point warp, confidence or marginal mean. A later independently informative cue updates g and queries the already-written conditional correction, while the observed-data skip is re-rendered under the same revised interpretation.

In implementation terms, keep (y_i, packetID, q_i(g)) plus an optional small *correction-only* response state r_i(g), and share the full current H3 proposal/source carrier. The output is B({y_i,q_i},X0)+R_phi({r_i,q_i},X0,currentLR). B is the shared bridge. R_phi starts at0; it may revise prior-correlated pixels outside a newly observed footprint. It is not hard pixel-null protection. Preserving unrelated identity uses each own actual X0 in predeclared independent queries, and is a shared training/readout control. The observable output still undergoes the same DC and explicit past-observation audit.

The specific empirical question is whether a learned *joint response* can retain and later apply a conditional correction with fewer nativeD/DiT calls or less persistent state than native re-decoding/replay, while maintaining the already-present measured detail. The carrier path makes this test interpretable: failure cannot be disguised as forgetting the observation before it reaches the model. Unlike the just-completed pilot, the write must occur **before** the disambiguating cue, and the early alternatives must be demonstrably nonseparable. A mixed-coordinate sketch is only one implementation; its formula is not new and does not establish a semantic factorization.

This remains close to conditional neural processes, joint filtering and learned group actions. Exact Bayes with the correct full prior/likelihood is not a meaningful target to claim principled superiority over: it already contains the required joint dependence. The candidate can only show a measured quality/cost advantage over explicitly finite or approximated controls. No originality is claimed from the split, conditional function, source persistence, replay or rebase equations themselves.

## Minimal discriminating protocol before another large training run

1. Use train-only episodes with an actual ambiguous early LR observation, and a later *independent* LR cue that disambiguates it. Natural repeated textures and subpixel correspondences are preferable to fabricated H3 identity modes. Keep original source images and exact measurement operators. Validate the prefix structure numerically before selecting a model: nontrivial early q(g|u), nonzero content/operator association, later evidence that changes the conditional explanation, and an actual readout error difference. If a future lower-resolution far observation is needed to leave uncertainty, predeclare that new protocol; do not relabel the present scale4/onehot data or choose sigma to manufacture entropy.
2. Write after the early prefix only; freeze the carrier then expose the late cue. Save both prefix payloads and perform prefix replay independently to prove no future access. The mathematical opposite-correlation example remains an interface unit test, not a natural H3 result. Do not describe two low-diversity seeds or operator offsets as newly created identities.
3. Use identical lossless carrier, X0, bridge, DC, evidence inference and learned parameter budget for: correction-only joint-action head; additive/no-interaction head; unrestricted joint DeepSets/CNP; same-bridge GRU/basic sequential flow; and fixed-operator/no-correction. Strong nonlearned controls are the full finite joint MHT or function grid, realD nonlinear/robust inverse, native/pixel-photo replay, and the original LR atlas. If the learned model retains original LR, the replay control retains it too.
4. Evaluate direct measured-detail retention, useful revisions after the cue, private GT HF error *and* displacement from own X0, sourcewise history swap/drop sensitivity, and operator-posterior calibration. Add real nonrigid/occlusion episodes from the existing motion data: the root's counterexample, where improved historical LR fit lowers HR quality, is the relevant failure of the current fixed observation model. Ordinary learned pair confidence is a necessary control, not the proposed mechanism.
5. Train from zero correction on actualD RGB/real LR objectives; use counterfactual history pairs with the same current query to prevent an anchor-only SR shortcut. A paired history effect must be present on a train interface check and remain correct on val. Latent response fit, nonzero gradients and closure alone are insufficient. Report the bridge's0-step output and every scheduled endpoint, without val-selected rank/gain changes.

I recommend completing B's staged δ→h→canonical→δ24→D→support/DC audit before choosing the neural side state. The quality-preserving bridge can be prepared immediately as a control. I do not recommend another random low-dimensional history encoder or a new300-step set variant on the current post-arrival/onehot dataset. The missing causal ambiguity/association test, and a direct observed-detail path, are substantive protocol/architecture repairs; neither alone is a publication contribution.
