# 第 0 步协议：冻结 H3 流式超分在回访时是否丢失细节身份

日期：2026-10-16。本文件在任何模型输出产生之前写定；之后只追加，不修改已定义的条目。

## 要回答的问题

现有基于 H3 的流式超分（无跨块记忆）在目标离开视野或被完全遮挡、再回来时，生成的细节是否与离开前不同。如果不同，这种差异是回访特有的，还是每个块都会重新生成。

本步不训练任何模型，不调任何参数。

## 数据

- 来源：LaSOT，第三方镜像 hf-mirror `l-lt/LaSOT@a97464600e8c1ab91eb91a47332a20732830585e`，逐成员 CRC 校验。
- 事件筛选只用标注，不看任何模型输出，规则见 `data/lasot_scan/protocol.json`（revisit_scan_v1）：
  - 消失 = full_occlusion 或 out_of_view，连续至少 30 帧；
  - 消失前后各 22 帧全部可见且有框；
  - 按 HR 尺度，前后窗口里目标框短边中位数都不小于 96px，框中心在 HR 裁剪区内。
- 选取规则：每个序列只取一个事件，取消失最长的那个；每个类别内按序列编号排序，最多取前 3 个；类别之间按字母序轮流取（每轮每类取 1 个），直到满 32 个或取完。
- HR/LR 构造与同事的 LaSOT 长流一致：源高大于 480 时用 Pillow LANCZOS 缩到 480 高（不放大），居中裁到 32 的倍数；HR 用 Pillow BICUBIC 下采样 ×4 得到 LR，不加噪声和压缩。
- 模型只读 LR，GT 只用于评价和配准。

## 流式块划分

与同事的长流协议一致：块 k 覆盖帧 [17k, 17k+22)，新输出为 [17k+5, 17k+22)（块 0 输出全部 22 帧），历史输出不回写，块之间没有状态，只有 5 帧低清上下文重叠。

每个事件处理 3 个块：
- kpre：新输出区间与 [s-22, s-3) 交集最大的块（s = 消失起点）；
- kpost：新输出区间与 [r+3, r+22) 交集最大的块（r = 回来的第一帧）；交集相同时取较早的块；
- kctl = kpre - 1（若 kpre = 0 则不设对照）。

## 方法

均为冻结 H3（ComfyUI 实现，权重与同事 H100 实验相同，SHA 校验），NPU 上运行，关闭 HF32：
- `vae_only`：官方引导预处理后 VAE 编码再解码；
- `innerdc`：同事的采样内观测约束，49 步 Euler、CFG 1、seed 101，在 sigma 下标 28/45/48 处执行 `z0 ← z0 + E(P25(D z0)) − E(D z0)`。

所有块使用同一个 seed 101（与同事一致，也是部署时的确定性设定）。

种子敏感度诊断（innerdc_s202）：每个事件的 kpre 块额外用 seed 202 跑一次 innerdc，其余完全相同。同事此前观察到 H3 带引导时不同种子的结果几乎相同，如果生成频带基本不随噪声变化，回访一致性就不能归功于"记住了细节"，而只是"没有生成细节"。因此同时报告：
- 同一帧上 seed 101 与 seed 202 输出之间的 ICR（不需要配准，掩码为目标框）；
- 生成频带能量比 `‖N(Y)‖² / ‖N(G)‖²`（目标框内），衡量模型在低清约束不到的频带里生成了多少能量。

## 测量

记号：Y 为输出，G 为 GT，均为 HR 的 [0,1] RGB。
- 生成频带：`N(x) = x − U(D(x))`，D 为浮点抗混叠 bicubic ×4 下采样，U 为 bicubic 上采样。这是低清观测约束不到的近似零空间分量。
- 配对：
  - 回访对 (a, b)：a 取自 kpre 落在 [s-22, s-3) 的新输出帧，b 取自 kpost 落在 [r+3, r+22) 的新输出帧；两边各取至多 3 帧（均匀间隔），共至多 9 对；
  - 对照对 (a', b')：kctl 最后一个新输出帧，配 kpre 第一个新输出帧（二者相差 1 帧）；两帧目标都可见才计算。
- 配准：取两帧目标框的外扩 10% 区域，把 b 的区域缩放到 a 的区域大小；在 GT 灰度图上计算 OpenCV DIS 光流（b→a），用前后向一致性（误差小于 1px）得到掩码 M。Y_b 与 G_b 用同一流场变换。生成频带 N(·) 先在整帧上计算，再随区域一起裁剪、缩放、变换。两帧目标框的缩放比（按框面积开方）超出 [2/3, 3/2] 的对丢弃，因为缩放会改变生成频带的能量；掩码在 a 的目标框内覆盖率低于 30% 的对也丢弃；两类丢弃数分别报告。
- 主指标，生成频带误差不一致比：
  `e_a = N(Y_a − G_a)`，`e_b = W(N(Y_b − G_b))`，在 M 内计算
  `ICR = ‖e_a − e_b‖² / (‖e_a‖² + ‖e_b‖²)`。0 表示两次生成的细节误差完全相同（身份一致），约 1 表示互不相关，大于 1 表示反相关。
- 辅助指标：
  - 生成频带变化比 `‖N(Y_a) − W N(Y_b)‖² / ‖N(G_a) − W N(G_b)‖²`；
  - 区域 LPIPS(Y_a, W Y_b) 与 LPIPS(G_a, W G_b)；
  - 各帧目标区域的 PSNR、LPIPS（对 GT）。
- 汇总：先在事件内平均，再在事件之间等权平均；报告逐事件数值，不做显著性检验之外的选择。
- 主比较：同一方法下回访 ICR 与对照 ICR 的事件配对差，以及 innerdc 与 vae_only 的对比。

## 判读（预先写定）

- 若 innerdc 的回访 ICR 接近 1，且明显高于其对照 ICR：回访丢失细节身份的问题存在，且是回访特有的，路线一有对象。
- 若回访与对照 ICR 都接近 1：问题存在，但本质是块间重新生成（闪烁类），路线一应先解决块间连续性。
- 若回访 ICR 明显低于 1 且与对照接近：现有方法回访时细节已基本一致，路线一的核心问题不成立，应换方向。
- 若种子间 ICR 接近 0 且生成频带能量比远低于 1：H3 在这个设定下几乎不生成细节，回访一致只是因为输出偏柔；此时"回访丢失身份"不是 H3 的瓶颈，瓶颈是细节生成能力本身。
- 数值判读同时配合目视面板（每个事件四列：G_a、Y_a、W Y_b、W G_b），面板按协议固定帧生成，不挑帧。

## 已知局限

- 配准误差会抬高 ICR，对照对只差 1 帧、运动小，配准更准，因此回访与对照的差会被配准误差放大。用 vae_only 的同口径数值作参照来判断这一偏差有多大。
- 同一 seed 在不同位置产生的噪声不同，这本身是无记忆方法的特性，不单独控制。
- 合成 bicubic 退化，不代表真实压缩视频。
