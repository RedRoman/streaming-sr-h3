# 第 1 步协议：冻结 H3 能否从高清参考图搬运细节

日期：2026-10-16。本文件在任何第 1 步模型输出产生之前写定；之后只追加，不修改已定义的条目。

## 背景与问题

第 0 步发现，冻结 H3 从低清生成的细节只有 GT 的 36%，回访时的身份丢失测不出来。本步要回答：给 H3 一张高清参考图时，它能否把参考里的真实细节搬到当前块的输出里。如果能，"记忆"的作用就可以从"保持身份"改为"提供 H3 自己从低清生成不出来的细节"。

## 数据与块

- 与第 0 步相同的 32 个 LaSOT 回访事件（`data/events/selection.json`），每个事件只处理回来后的块 kpost。
- 评价帧：kpost 的新输出帧（[17k+5, 17k+22)）中目标可见、目标框短边至少 16 像素的帧。
- 模型只读 LR 和参考图；参考图来自目标消失之前，GT 只用于评价。

## 参考图（每个事件一张，帧号 f_ref = pairs_revisit_a 的中间帧，即消失前的帧）

- `gt`：f_ref 的 HR GT 整帧。这是"完美记忆"的上界。
- `self`：第 0 步 FL2VA innerDC 在 f_ref 的输出整帧。这是部署时记忆能拿到的东西。
- `wrong`：选择顺序中下一个事件（循环）在其 f_ref 的 HR GT 整帧，内容不相关，用来检查模型会不会硬搬错误纹理。
- `none`：不给参考图。

参考图按官方 MiniMaxH3ReferenceToVideo 节点的 `match` 规则缩放（只缩小、保持长宽比、面积对齐生成画布、32 的倍数），同时进入 DiT（VAE 编码后的参考行）和文本编码器（`<Picture 1>: <图像块>`）。

## 模型与条件

- DiT：Comfy-Org/MiniMax-H3@e5eb578 的 `minimax_h3_ref2va_pruned_bf16`（SHA256 37c0da79…）。
- 文本编码器：同仓库 `qwen3vl_32b_minimax_h3_bf16`（SHA256 600d567f…），在 NPU 上运行。注意同事用的是 NVFP4-AWQ 版本，本步所有条件统一改用 BF16 版本重新编码。
- 提示词：
  - `none`：同事的中性恢复提示词原文。
  - `gt` / `self` / `wrong`：参考图块 + 同一中性提示词 + 追加一句 " <Picture 1> is a high-resolution reference of the same scene; reproduce its fine details where they appear in the video."
- 低清条件：与第 0 步相同的 LR 引导关键帧（官方 AddGuide 预处理，resolved_frame_index 0）。
- 采样：与第 0 步 innerdc 完全相同（49 步 Euler、CFG 1、seed 101、sigma 下标 28/45/48 处像素投影修正，投影在 NPU float32 上计算）。
- 额外参照：第 0 步 FL2VA innerDC 在同一 kpost 块上的输出（`fl2va`），不重跑。

## 指标

对每个评价帧，在目标框内（不外扩）计算：
- PSNR（对 GT）；
- LPIPS（对 GT，目标框外扩 10% 裁剪，最短边不足 64 时放大到 64）；
- 生成频带能量比 `‖N(Y)‖² / ‖N(G)‖²`；
- 生成频带与 GT 的余弦 `cos(N(Y), N(G))`；
另算整帧 PSNR 与 LR 一致性（输出经同一 ×4 下采样后与 LR 的 RMSE）。N(·) 与第 0 步相同。

先在事件内对帧平均，再在事件间等权平均。主要比较为各条件相对 `none` 的事件配对差，报告均值、事件级 bootstrap 95% 置信区间（10000 次重采样，种子 0）和改善事件数。

## 判读（预先写定）

主比较为 `gt − none`：
- 若目标框 PSNR 平均提高至少 0.3 dB，或 LPIPS 平均降低至少 0.02，且置信区间不跨 0：冻结 H3 能从参考搬运细节，继续评估 `self`；
- 否则：冻结 H3 的参考通路在这个设定下不能搬运细节，要么需要训练参考适配器，要么换方向。

`self − none` 决定部署价值，判读阈值同上。
`wrong − none`：若能量比提高而 PSNR 下降，说明存在搬运错误纹理的风险，必须在报告中写明。
`none − fl2va`：只用于说明换成 Ref2VA 权重本身的影响，不参与主判读。

## 冒烟测试

全量之前，先用选择顺序的前两个事件（bicycle-1、bottle-14）跑 `none` 和 `gt`，只检查流程是否跑通、输出是否正常、显存与耗时；不据此调整任何设定。冒烟测试的输出会保留，并作为全量结果的一部分（设定相同）。

## 已知局限

- 参考图是整帧而不是目标裁剪；回来后姿态和尺度可能已变，参考与当前帧不完全对应，这是记忆的真实情况。
- Ref2VA 权重在训练时可能没见过"关键帧 + 参考图"同时出现的组合；`none` 与 `fl2va` 的对比会显示这种组合本身的影响。
- 合成 bicubic 退化，不含压缩。
