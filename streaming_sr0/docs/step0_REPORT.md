# 第 0 步结果：冻结 H3 流式超分的回访细节身份

2026-10-16 15:55。协议见 `PROTOCOL_step0.md`（判读规则在出数前写定）。数据为 LaSOT 32 个回访事件（29 个类别，消失 30–212 帧），832×480 或原生更小尺寸，合成 bicubic ×4。在 30794 的 4 张 910B 上运行，共 224 个块，0 失败，模型不读 HR。

## 预注册指标

| | VAE 基线 | innerDC |
|---|---:|---:|
| 回访 ICR（7 个可用事件） | 0.507 | 0.586 |
| 对照 ICR（同 7 个事件，块边界相邻帧） | 0.190 | 0.269 |
| innerDC 减 VAE（回访 / 对照） | | +0.078 / +0.079 |
| 换种子的 ICR（32 个事件） | | 0.064 |
| 生成频带能量 / GT（32 个事件） | 0.17 | 0.36 |

- 可用事件少：288 个回访对中，90 个因尺度变化、173 个因配准覆盖率被丢弃，只剩 7 个事件的 25 对，并且偏向"回来时姿态相近"的情况。
- 回访对的配准质量明显差于对照：GT 自身对齐后 PSNR，回访 20.9–28.9 dB，对照 28.6–38.5 dB。VAE 和 innerDC 的"回访减对照"差距一样大（都约 +0.32），而 innerDC 比 VAE 多出的不一致在回访和对照处也一样（+0.078 和 +0.079）。所以回访处没有观察到超出普通块边界的额外身份丢失；剩下的差距由配准和外观变化解释。
- 触发的预注册规则："种子间 ICR 接近 0 且生成频带能量比远低于 1：H3 在这个设定下几乎不生成细节，回访一致只是因为输出偏柔；瓶颈是细节生成能力本身。"

## 事后诊断（看过上面数字后才加，不属于预注册内容）

全部在同一帧上比较，不需要配准：

| | VAE | innerDC |
|---|---:|---:|
| 同一帧被相邻两个块各生成一次，生成频带的相对变化 | 0.13 | 0.35 |
| 换种子，生成频带的相对变化 | | 0.32 |
| 生成频带与 GT 的余弦 | 0.33 | 0.37 |
| innerDC 比 VAE 多出的部分与 GT 残差的余弦 | | 0.22 |
| innerDC 多出部分的能量 / GT | | 0.17 |

- innerDC 确实生成了一些细节（生成频带能量约为 VAE 的 2 倍），其中约三分之一由噪声决定，相邻块对同一帧的渲染变化和换种子差不多大。这是无记忆分块带来的真实不一致，但它出现在每个块边界，不是回访特有的。
- 生成量本身小：只有 GT 的 36%，和 GT 的方向一致性弱（余弦 0.37）。种子 ICR 接近 0，是因为误差主要来自"没生成出来"的部分。
- 目视：回访前后的输出一致，但都偏软，水杯上的文字在两种输出里都不可读。

## 结论

1. "回访时丢失细节身份"在冻结 H3 上测不出来，不是当前瓶颈。
2. 瓶颈是 H3 从低清生成的细节太少，且与 GT 对得不准。在这个前提下，给 H3 加一个保持身份的记忆，保持住的细节也很少，视觉收益有限。
3. 块边界上存在可测的再生成不一致（innerDC 0.35），但量级受制于第 2 点。

## 局限

- 回访指标只有 7 个事件可用，置信度低；配准方法对姿态变化大的回访失效。
- 合成 bicubic 退化，没有压缩。
- 只测了 seed 101 和 202，以及同事那套 innerDC 设定（49 步、CFG 1、3 个修正点）。
- bicycle-1 的 kctl 块投影用的是 CPU float64，其余块是 NPU float32（同一块上两者最大差 3.6e-7）。
