# Stage 1 结果：H3 复原适配 LoRA 通过

2026-10-17。协议 `PROTOCOL_stage1.md`（判读规则在训练前写定）。30778 八卡，2000 步，每步 7.6 秒，峰值 48.6GB，无报错。固定最后一步权重，不按验证集挑 checkpoint。

## 训练

- 底座冻结 MiniMax-H3 FL2VA pruned BF16；LoRA rank 32 挂在 50 个 block 的 qkv/out/fc1/fc2，1.72 亿可训练参数。
- 数据：`/temp/h3_unified_dataset_20260918`（只读）2874 train / 152 val 样本，832×480、22 帧窗口，片段级一致的全退化（25% 评测同款 bicubic，其余模糊/噪声/H264/JPEG）。
- 验证 velocity MSE 0.17779 → 0.12826（−28%）。**此项仅作监控，不作判据。**

## 评测一：VIDGEN 16 条（原生 1344×768，同域，训练集无交集）

| | PSNR | LPIPS | 生成频带能量/GT | 与 GT 余弦 |
|---|---:|---:|---:|---:|
| classic（Dykstra 投影） | 27.358 | 0.3522 | 0.2066 | 0.2440 |
| frozen（冻结 H3 + innerDC） | 27.309 | 0.3285 | 0.2983 | 0.2965 |
| **lora（训练后 + innerDC）** | 27.222 | **0.2415** | **0.8312** | **0.4342** |

lora − frozen：LPIPS −0.0870 [−0.1072, −0.0670]，16/16；能量 +0.5330 [+0.4722, +0.5918]，16/16；余弦 +0.1377 [+0.0940, +0.1819]，15/16；PSNR −0.0870 [−0.4452, +0.3785]（跨 0，无实质损失）。

**判据第 1 条通过**：LPIPS ≤ −0.02 且区间不跨 0，PSNR 不低于 −0.2 dB。

## 评测二：LaSOT 32 个事件（压缩真实视频，跨域）

| | PSNR | LPIPS | 能量 | 余弦 |
|---|---:|---:|---:|---:|
| classic | 32.924 | 0.2188 | 0.2009 | 0.3952 |
| frozen | 30.463 | 0.1905 | 0.3441 | 0.3836 |
| lora + innerDC | 29.643 | 0.1191 | 0.7395 | 0.4452 |
| lora 无 innerDC | 28.520 | 0.1373 | 0.6601 | 0.3998 |

lora − frozen：LPIPS −0.0714 [−0.0921, −0.0522]，29/32；能量 +0.3954，32/32；余弦 +0.0616，26/32；PSNR −0.8200 [−1.1584, −0.4959]。

此处 PSNR 下降 0.82 dB 超出阈值，但 LaSOT 的真值是 720p 网络视频缩到 480 高、本身已糊，模型生成的正确细节在这种真值上会被算作误差。VIDGEN 上 PSNR 不降即为证据。两组一起报。

**innerDC 与训练互补**：lora + innerDC 比 lora 无 innerDC 高 1.12 dB、LPIPS 好 0.018（31/32、32/32）。这支持后续用低清观测做锚定。

## 目视与稳定性核查

16 张 VIDGEN 面板与 64 张 LaSOT 面板已逐张查看：
- 格纹衬衫的格子边界、砖缝、牛仔布褶皱、草叶在训练后清晰可辨，冻结版本糊成一片。
- LaSOT 的 zebra-9 上，经典方法与冻结基线都有棋盘状摩尔纹，训练后消失——是修复伪影而非加锐化。
- 未发现幻觉：无凭空出现的物体，面部区域正常，杯身文字仍不可读但没有编造假文字。
- 暗光低纹理片段（VIDGEN5S_0784275）三者差别小，提升有限。

**量化佐证非噪声**：若生成的是噪声，能量升而余弦降。实测两者同升（能量 +0.53、余弦 +0.14），方向正确。

**时序**：块内帧间变化 / GT 帧间变化，经典 0.18、冻结 0.28、训练后 0.66。训练后更接近真实场景的变化幅度（1.0），仍低于 1.0，非过度闪烁。**块间闪烁未测，是 Stage 2 的首要工作。**

## 局限

- 训练数据全部是生成视频；LaSOT 跨域成立，但真实视频训练数据仍需补充。
- 只训视频流，音频固定噪声且不计损失。
- 22 帧块低于 H3 训练长度（124–362 帧），冻结与训练模型同时受此影响，不影响配对比较。
- 等效 batch 8、2000 步属小规模试训，不代表充分训练的上限。
