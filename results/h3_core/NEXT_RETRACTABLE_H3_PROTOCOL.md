# Next hypothesis: late geometry must relocate evidence, not merely reject it

Status: **superseded as a main-method proposal after original-paper review**. BundleFusion already performs symmetric de-integration/re-integration after pose revision, and ElasticFusion deforms its map after loop closure. Do not launch another signed-replay/set experiment from this document. The narrower unresolved question is learned preservation of content–operator joint dependence, examined in `REVISABLE_OPERATOR_REVIEW.md`. No new training or sealed confirmation evaluation has started. This original proposal is retained for an honest design history.

The current evidence argues against another loop penalty or X0-PCA gate. Fixed latent complements block useful cue response without guaranteeing decoded identity. Actual H3 conditional output is not yet stronger than a VAE guide or classical inverse. Separately, the real-motion experiment found that fitting a confidently wrong historical camera warp can lower the LR objective while damaging the true frame. The next mechanism should treat old observation interpretations as revisable state and test whether stored detail can be relocated after a later geometric explanation arrives.

Proposed state: retain each raw LR packet, timestamp, packet ID, current correspondence version, its uncertainty, and an individually addressable native-H3 condition token. Do not compress irreversible RGB/latent additions into a single mean or fixed channel subspace. A trainable **retraction-and-relocation operator** reads a packet's old/current warp, overlapping later LR witnesses, its previous contribution, and the frozen current H3 latent. It predicts (1) a small residual warp/occlusion update and (2) a signed latent influence field that removes the old contribution and inserts the same evidence at its revised location. Its RGB effect is evaluated through the actual H3 decoder. All24 channels are available, with soft reference-query preservation shared by every learned control; there is no hard pixel-null or arbitrary PCA private freeze.

The intended testable difference is not a new confidence weight: corrected old detail should reappear at a newly supported location while disappearing at the old one, even when the original patch is no longer visible. The operator's signed influence must change when the same archived LR packet receives a new LR-supported correspondence version. A normal fixed-operator inverse cannot perform this reassignment. An all-history DeepSets network can in principle do it, so a set model that receives every raw packet and the revised geometry is mandatory. A joint robust alignment-plus-RGB inverse is also mandatory; comparing only to fixed wrong geometry would be inadequate.

Trainable implementation: two shared small networks, not a new DiT backbone. A packet alignment head predicts a bounded LR-coordinate correction and visibility from bidirectional overlap residuals. A native-latent influence head predicts removal/insertion fields conditioned on both old and revised packet renderings and current H3 features. It is initialized to zero and uses a shared current-LR anchor. The state keeps provenance so a packet's contribution can be removed once and recomputed under the new version. The frozen H3 DiT is used for paired counterfactual condition responses, not replaced with a VAE-only mean; direct native guide gradients use the repaired official-BF16 IO math. Counterfactual response supervision is a training teacher, never an extra future observation at inference. Classical cavity/subtraction, geometric warping, and native H3 conditioning are components, not claimed inventions.

Minimum diagnostic before another large training run: use the same four train/two val sources only, plus their existing genuine seed101/202 H3 carriers. Create one fixed short pan/overlap trajectory per source. An early near patch receives a predefined small correspondence bias (translation and one nonrigid displacement); a later overlapping LR cue provides a distinguishable correction. The operator sees the biased map and actual LR overlap, not GT geometry. Exact geometry is reserved for train supervision and an oracle headroom diagnostic. Generate paired actual H3 responses to the biased and corrected condition guides with the same sampler noise, official49 schedule and native22 layout. These are controlled natural-image camera sequences, not real-motion confirmation or fabricated multimodal samples.

First measure whether the corrected native H3 response improves the newly supported region and whether it contains a relocatable high-frequency component beyond corrected VAE-guide E/D. If it does not, do not train a response router and call it H3-prior progress: use the same small experiment to test the resource agent's properly adapted SR backbone, with its checkpoint fixed before comparing mechanisms. Teacher response quality and all guide/call counts must remain explicit. The previous pilot's weak natural seed diversity cannot support claims about broad independent semantic identity.

If the response/gradient interface is finite and nonzero, run a single fixed development budget, not a gain sweep: 300 updates each for proposed relocation, the same-capacity all-history set readout, a same-capacity ordinary recurrent readout, and a retraction-disabled ablation. Every head receives identical LR packets, native response tensors, source carriers, query loss, current DC, and runtime calls. Add fixed wrong-geometry inverse, LR-confidence rejection, joint robust alignment-plus-inverse, oracle-corrected inverse, and corrected VAE-guide readout. The exact finite-ensemble control may revise weights, but cannot relocate an atom it never contained; that limitation is not itself evidence for the learned operator.

Predeclare three simultaneous outcomes: (a) less error at the newly justified detail location, (b) removal of the same detail from its contradicted old location, and (c) no extra high-frequency drift on held-out X0 reference queries compared with the same-capacity set model. Also report full/ROI PSNR, SSIM/LPIPS, actual LR residuals under both old and revised operators, geometry error for this controlled diagnostic, and per-packet retraction idempotence. A pure lower LR residual is insufficient. Evaluate with and without the DiT response so a VAE/warp-only gain cannot be attributed to H3 generative reasoning.

The hypothesis fails at this stage if corrected H3 gives no useful conditional headroom, if learned routing only matches robust geometry optimization/DeepSets, or if correction is bought by unrelated reference drift. Positive development results would justify a frozen protocol on separate real nonrigid motion; they would not yet establish long-revisit streaming performance. No source-space optimizer, generic posterior warm start, exact particle reweighting, or order-invariant sum is being renamed as the new mechanism.
