# Revisable observation operators: original-paper audit and next hypothesis

Status: read-only theory work after the completed fixed H3-response pilot. No new GPU experiment, confirmation evaluation, or claim of novelty. The preceding `NEXT_RETRACTABLE_H3_PROTOCOL.md` is superseded as a main-method proposal.

No broad novelty claim follows from the table.

## Relationship to B3R

The implemented B3R (`src/h3_factorized/revision_model.py`) learns a packet lift h and an appearance action. Its closed-action branch keeps weighted first moments that can be exactly rebased when an external causal LR photometric controller changes the capture group's appearance estimate. This is stronger than an irreversible online average: old evidence is reinterpreted without full neural replay. The exact moment/action algebra is a component; whether its learned lift/action improves actual decoded restoration and cost is being tested separately.

My superseded raw-packet retraction protocol shares its causal revision motive but retains individual packets and recomputes their effects. That is closer to ordinary re-integration/replay and offers no clear new core. Replacing the photometric action with a warp, or putting the same packets into a DeepSets head, does not fix this weakness.

An unresolved representational difference is **joint dependence before an interpretation is resolved**. Suppose content phase c and displacement g each have marginal probability 1/2 on +/−, but one history supports c=g and another c=−g. Their means and separate marginals are equal. A later geometry cue selecting g=+ requires opposite content outcomes. A point-estimated controller followed by moment rebase has already discarded that distinction. This is an elementary identifiability probe, not a claim about H3's actual distribution and not a new Bayesian principle. Exact four-atom joint MHT solves it and must be retained as an oracle control. A joint-feature set/conditional-neural-process network can also learn it; comparing only with independent-marginal or point-GRU baselines would be weak.

## Candidate learning mechanism: preserve a conditional response function

The specific hypothesis worth checking is a **compressed operator-conditioned H3 response function**, rather than a single fused detail tensor or a bank of already committed frames. Its memory should answer “what detail does this same persistent H3 carrier support if the old measurement correspondence is g?” The response function is retained while new geometry evidence changes which g is queried. New detail evidence updates the conditional function, including its content–operator coupling; it need not freeze unrelated physical-null pixels or arbitrary latent channels.

One implementable form is a small conditional neural operator with memory coefficients m, a persistent actual H3 carrier u, and continuous operator coordinates g. It outputs a full24-channel native latent response H(m,g,u), together with a low-dimensional joint association density q(g|u,m). Use a low-rank mixed branch whose coefficients depend jointly on g and u, plus a matched additive-only ablation. Both see the same data. A purely separable appearance value plus geometry key cannot pass the opposite-correlation probe. The train objective includes paired actual H3 conditional responses over several g at the same u, and their mixed finite-difference responses; zero-reference and true LR/RGB constraints remain shared with controls. This learns a family of conditional effects, rather than just the endpoint marginal or a scalar cue gain.

Bayesian reweighting of operator hypotheses, counterfactual supervision, low-rank approximation, and conditional neural operators are existing tools. The potential contribution would have to be demonstrated as accurate preservation of **this joint conditional function under streaming compression and later correction**, with useful actual H3 detail, at a declared memory/readout budget. It is not established merely by implementing those tools. Exact arbitrary future revision cannot be guaranteed after lossy compression; operator range, retained sketch size, and conditional approximation error must be specified.

The difference from classical re-integration is that no single geometry/world texture is committed before the cue; the nonlinear conditional detail function can change content after geometry disambiguation. The difference from B3R is unresolved content–operator dependence, not just an externally supplied appearance coordinate acting on first moments. The difference from basic sequential flow is supervision of a multi-operator response family with shared source correspondence rather than only successive posterior marginals. The difference from ordinary replay is storage/query of a compact conditional function instead of re-running every packet. None of these differences guarantees an advantage over a strong joint-set/CNP model; that comparison is the central falsifier.

## Minimum discriminating experiment, before another broad run

1. **Representation check, no new DiT calls.** Implement the two opposite-correlation four-atom probes above, with exactly equal separate marginals. Compare proposed mixed memory, additive/independent memory, parameter-matched joint DeepSets/CNP, and exact joint MHT. Use it only to verify that the code retains conditional dependence and that the intended ablation removes it. Passing is necessary interface evidence, not restoration progress.
2. **Actual H3 response check on the existing four train/two val development sources.** Fix four small correspondence offsets spanning a declared continuous operator range and seeds101/202. Generate official native22/49-step responses to those LR-only guides: at most48 actual H3 samples/2,352 full50-block forwards. Same seeds, guides, tokens, noise and source carriers across every learned/control method. Do not manufacture extra texture modes. Oracle geometry is a teacher/diagnostic only; inference geometry evidence comes from actual LR overlap. The current tiny natural H3 seed diversity is explicitly retained as a limitation.
3. **Decisive fit, fixed budget only if the response is finite/nonzero.** Train at most300 updates for mixed conditional memory, additive memory, and joint-set/CNP, with mechanically matched capacity, identical actual-D supervision and carrier-query preservation. Hold out one interior operator coordinate and one fixed composition from the training response grid; evaluate the whole predeclared val pair without source selection. Dense joint-grid/MHT and a joint robust geometry-plus-RGB inverse are strong controls, not targets that the student is expected to surpass under their own exact specified risk. Include the same response-function fit using VAE guides alone.
4. **Require three pieces of evidence together.** The corrected operator must recover the right newly justified detail, remove contradicted detail, and preserve the actual source carrier's unrelated high-frequency queries at least as well as the joint-set/CNP control. Report response-function error, mixed-response error, posterior association calibration in the controlled probe, real LR residuals, PSNR/SSIM/LPIPS, state bytes and actual E/D/DiT calls. Pure lower LR residual or exact path equality is insufficient.

This candidate is rejected if the H3 conditional family has no VAE-independent headroom, if an ordinary joint-set/CNP model matches it at the same budget, or if the only gain comes from exact reweighting/classical geometry correction. The current report therefore recommends a small representation/response feasibility check, not automatic rollout of another nominal new method. No sealed DIV2K source is used. A positive result would still require fixed-checkpoint confirmation on separate real nonrigid motion and a long revisit protocol.

The literature check therefore has **not yet established an original mechanism**. The proposed mixed-response learning is a concrete representational hypothesis and a way to expose failure, not permission to present conditional neural inference as a new principle. The completed negative pilot remains the main empirical finding. Existing-cache cue-by-noise mixed-response measurements can be audited on CPU before allocating further H3 calls; that interaction must not be confused with identified content–pose dependence or previous-X0 source identity.
